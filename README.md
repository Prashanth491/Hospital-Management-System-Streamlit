# 🏥 Hospital Management System (Python + Streamlit + MySQL)

A complete hospital management application built using:

- Streamlit (Frontend)
- MySQL (Database)
- Python Services (Backend)
- Matplotlib (Charts & Analytics)

## Features
✔ Admin Dashboard  
✔ Manage Patients  
✔ Departments  
✔ Doctors  
✔ Appointments  
✔ Visits  
✔ Treatments  
✔ Billing  
✔ Role-based Login (Admin / Patient / Doctor)

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Start app:
   streamlit run Hospital.py
